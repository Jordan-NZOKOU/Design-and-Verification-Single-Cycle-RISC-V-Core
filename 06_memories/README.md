# Milestone 06 - Instruction and Data Memories

<p align="center">
  <img src="../13_diagrams/svg/14_memory_architecture.svg" alt="Milestone 06 - Instruction and Data Memories diagram" width="100%">
</p>

## Engineering objective

Provide deterministic behavioral memory models with byte-addressed processor interfaces and word-indexed storage arrays.

## Design overview

Instruction memory is a 256-word asynchronous ROM initialized with `$readmemh`. Data memory is a 256-word array with asynchronous read and synchronous write. Both modules translate byte addresses to word indexes with `A[9:2]`. Reset masks ROM output with a NOP and clears the data array for deterministic simulation.

### Architectural contract

Dropping address bits `[1:0]` is correct for aligned 32-bit words because addresses 0, 4, 8, ... select array entries 0, 1, 2, .... The ROM parameter `MEMFILE` lets each integration milestone provide its local program image.

## Interface contract

| Signal | Direction | Contract |
|---|---|---|
| Instruction `A[31:0]` | input | PC byte address |
| Instruction `RD[31:0]` | output | Fetched instruction or reset NOP |
| Data `clk`, `rst_n`, `WE` | inputs | Write/reset control |
| Data `A[31:0]` | input | ALU-generated byte address |
| Data `WD[31:0]` | input | Store word |
| Data `RD[31:0]` | output | Asynchronously read word |

### Timing model

Combinational outputs settle after input changes according to simulator delta
cycles. Any architectural write occurs only on the rising edge defined by the
module contract. `rst_n` is active-low and synchronous wherever state is reset.
The milestone does not introduce hidden state beyond the documented registers or
memory array.

## Verification strategy

The testbench is directed, self-checking, and CI-friendly. It initializes every
stimulus signal, uses reusable check tasks, compares with `!==` to reject unknown
values, accumulates mismatches, optionally writes a VCD when `DUMP_VCD` is
defined, and ends with one unambiguous verdict.

- Check reset-visible outputs.
- Read three known ROM words at byte addresses 0, 4, and 8.
- Write data words to byte addresses 0 and 4.
- Verify asynchronous readback and retention of the other word.
- Disable `WE` and prove that a write attempt is blocked.

### Signals to inspect in GTKWave

`instr_addr`, `instr`, `data_addr`, `write_data`, `write_enable`, `read_data`.

### Expected verdict

```text
TEST ... PASSED
```

A mismatch prints the observed and expected values before `$fatal` terminates the
simulation with a failing status.

## Run

### QuestaSim or ModelSim

```bash
cd 06_memories
vsim -c -do run_questa.do
```

The script recreates the work library, compiles sources in dependency order,
runs the testbench to completion, and writes the milestone VCD.

### Icarus Verilog

From the milestone directory:

```bash
./run_iverilog.sh
```

From the repository root:

```bash
make test-project PROJECT=06_memories
```

### Waveform review

```bash
gtkwave *.vcd
```

Waveform review complements the automated checks; it is not the acceptance
criterion by itself.

## Review focus

Confirm the byte-to-word mapping, read/write timing, reset behavior, and the modeling boundary between a convenient simulation memory and a target-specific SRAM/BRAM macro.

A senior review should also confirm that comments describe intent and timing
rather than restating syntax, that all combinational paths have deterministic
defaults, and that the testbench proves the stated interface contract.

## Integration role

Instruction memory closes the fetch path. Data memory is enabled in milestone 9 and feeds the result mux for LW.

The milestone is self-contained by design. Repeated core files are compared by
`scripts/repository_check.py` so independence does not permit silent divergence.

## Scope boundary

Only aligned 32-bit accesses are modeled. Byte enables, latency, ready/valid handshakes, misalignment exceptions, and external buses are not included.

This boundary is intentional and is not an implicit compliance claim beyond the
behavior verified by this milestone.
