# Changelog

All notable release changes are documented here.

## 6.0.0 - 2026

### Changed

- rebuilt all 23 engineering figures as native Draw.io documents;
- added a combined 23-page Draw.io library for portfolio review;
- synchronized SVG, PNG, and PDF exports from the same geometry model;
- redesigned the processor architecture and final datapath using a dedicated
  processor-block visual language;
- added a six-sheet Excel instruction-set architecture workbook;
- updated the report, README, scripts documentation, and release checks for the
  Draw.io and ISA-workbook artifacts.

### Preserved

- Verilog executable behavior;
- supported instruction subset;
- test vectors and acceptance criteria;
- final program and expected architectural state;
- eleven-milestone integration structure;
- English repository and report content.

## 5.0.0 - 2026

### Changed

- translated the complete repository and report to English;
- renamed remaining French milestone and asset paths to English;
- expanded engineering comments across RTL, testbenches, Python, shell,
  PowerShell, Make, Questa, assembly, and automation files;
- substantially expanded the root README and every milestone README;
- added a dedicated root **Scripts and automation** section covering every
  public tool and execution path;
- replaced the previous diagram set with 23 reproducible professional figures
  generated by Graphviz and Matplotlib in SVG, PNG, and PDF;
- added English report source and build automation;

### Preserved

- Verilog executable behavior;
- supported instruction subset;
- test vectors and acceptance criteria;
- final program and expected architectural state;
- eleven-milestone integration structure.

## 4.0.0

- prepared the code and GitHub documentation in English while retaining a French
  report;
- added per-milestone README files and repository automation.

## 3.0.0

- expanded the essential RISC-V concepts chapter.

## 2.0.0

- added heavily commented testbenches and milestone diagrams.
