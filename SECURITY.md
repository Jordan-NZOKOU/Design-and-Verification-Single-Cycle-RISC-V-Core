# Security Policy

Nexvantis is an RTL portfolio project and does not process secrets or expose a
network service. Security reports are still welcome for repository automation,
workflow injection, unsafe command handling, or malicious input behavior in the
assembler/report tooling.

Do not publish a sensitive exploit in a public issue. Contact the maintainers
privately through the repository owner account and include the affected file,
reproduction steps, impact, and a proposed mitigation when available.

The processor itself is not claimed to implement security boundaries,
privileged execution, memory protection, constant-time behavior, or fault
resistance.
